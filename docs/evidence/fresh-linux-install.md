# Fresh supported-Linux installation

## Outcome

`voice-agent install` now owns one fresh per-user Linux `x86_64` systemd/NVIDIA path. It verifies the signed stable channel, exact platform artifact and complete safe archive plus host/GPU/assets/space before managed-path mutation. It creates canonical private XDG state, safe local-only defaults, an immutable exact release and one generated user unit. Only exact service/build, five unique compatible ready voice components, admission and loopback listener custody commit selected/healthy truth.

An identical command re-probes and reports already healthy. A partial, foreign, symlinked or previously failed state is preserved and routed to doctor/recovery. Candidate readiness failure stops and disables the candidate, leaves no selected/healthy record, retains bounded content-free evidence and returns nonzero. AgentEnvironment/Docker and Telegram remain optional after ordinary voice success.

## Deterministic evidence

The launcher phase of `./verify` uses only disposable XDG roots, generated in-memory signing keys, bounded artifact-entry bytes and injected host, space, asset, linger, user-service and readiness owners. It covers:

- pristine signed install and exact mode/ownership/default/unit records;
- exact one-start, release/build, 5/5 readiness, admission and loopback listener custody;
- independent optional AgentEnvironment/Telegram degradation;
- unsupported host and missing noninteractive linger privilege;
- forged signature, unsafe/incomplete archive and genuine space refusal before mutation;
- interruption before and after durable filesystem/service phases, exact resume and single service start;
- identical healthy reconciliation;
- partial, pre-existing, foreign and symlinked path preservation;
- absence of generated secret values and private/content paths from public output and durable public records;
- deterministic Node.js 26 SEA packaging with the install owner embedded in the same executable.

The full canonical output is saved as the task verification artifact.

## Nonclaims

No production signing key, channel endpoint or release artifact was provisioned or published. The repository build therefore fails closed before mutation when production release authority is absent. No real NVIDIA/model runtime, download, `sudo`, linger, user systemd, listener, reboot, microphone, audible voice, Docker, AgentEnvironment, Telegram, network or physical/full-stack behavior was exercised. No live stand, legacy root/service, external exposure, firewall, Docker group/daemon or shared service was inspected or changed.

General update, automatic rollback, reachability GC, launcher self-update, legacy adoption/migration, AgentEnvironment creation/preservation, uninstall and macOS runtime remain later slices. Deterministic injected interruption is not VM power-loss or filesystem crash-consistency evidence; those remain in the platform/power-loss tier.
