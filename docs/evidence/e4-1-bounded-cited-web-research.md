# E4.1 bounded cited Web research evidence

**Scope:** deterministic PR evidence for issue #40.  
**Command:** `./verify`  
**Authority:** frozen synthetic pages/search/error/cache/redirect transcripts and fake Docker only.

## Exercised contract

- A frozen natural current-information task refines its query, independently fetches two origins, combines convenience Web calls with ordinary shell/script and file work, persists artifacts under `/workspace` and `/cache`, and passes by useful concept outcome rather than exact wording or tool order.
- Active AgentRun/decision v2 binds each final citation to a controller-owned completed receipt. Tests compare displayed URL and artifact SHA-256 back to the receipt and require cited answer spans. Invented, failed, missing, or spanless bindings fail closed.
- Receipt fixtures expose retrieval time, redirects, HTTP failure, observed/saved bytes, SHA-256, truncation, title, extraction error, cache use, staleness and stale-on-network-failure truth.
- Tool/page role markers, hostile instructions, fake citations, and serialized operations remain inert result bytes. Only the next separately parsed and admitted model decision dispatches work.
- The adversarial fixture records the accepted effects `rw_workspace_changed` and `synthetic_credential_used`; it does not claim prompt-injection prevention or credential confidentiality from the agent.
- The same fixture preserves an unmounted host sentinel and reaches no Docker socket/CLI, host process/control/service interface, device, undeclared mount, second environment, dynamic mount/port/credential configuration, lifecycle operation, host tool, or alternate-runtime fallback.
- Model-needed bytes and persisted artifacts remain exact. Only the final human answer and citation title/claims/spans redact an injected synthetic credential; normalized displayed URLs remove userinfo and redact sensitive query values by construction.
- Failed/inaccessible research produces a bounded failed receipt, retains prior state, triggers no automatic ambiguous mutation retry or environment teardown, and needs no fabricated citation.

## Frozen outcome rule

The scorer checks all of the following without selecting a provider or workflow:

1. required outcome concepts occur in the answer;
2. at least two distinct successful search-query hashes demonstrate refinement;
3. citations cover those concepts;
4. citations equal completed receipt URL/hash facts;
5. at least two independently fetched URL origins are cited;
6. the release decision/operation bounds are respected.

Citation traceability is not a truth guarantee. Factual/source quality remains later human/exact-model evidence.
